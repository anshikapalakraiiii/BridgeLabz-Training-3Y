The CSS Box Model

Content, padding, border, and margin — visualized as layers.

margin
border
padding
content

Content

The actual text or elements inside the box — sized by width and height.

Padding

Space between the content and the border, inside the box.

Border

A visible (or invisible) line that wraps the padding and content.

Margin

Space outside the border, separating this box from its neighbors.
