Gradients in CSS

Linear Gradient

This section uses background: linear-gradient(...) to blend colors along a straight line. It also uses background-attachment: fixed; so the gradient stays in place while the page scrolls, creating a parallax-like feel.

Radial Gradient

This section uses background: radial-gradient(...), which blends colors outward from a central point instead of along a line.
